# Repository work

This repository contains workflow guidance, an installable skill, and a small COMSOL Java API example.

- Keep public instructions, references, code comments, and example documentation in English; maintain README.zh-CN.md as the Chinese translation.
- Keep the workflow independent of any particular paper. Document scientific attribution and assumptions inside the relevant example.
- Preserve user models and outputs. Run examples into a new output directory and do not load or overwrite unrelated research files.
- Do not commit COMSOL installations, licenses, MPH solution files, publisher PDFs, credentials, caches, generated class files, or personal machine paths.
- Keep supported and actually checked behavior clear. A completed batch process alone does not establish numerical or physical validity.
- Run relevant offline checks after edits. A solver check requires a suitable licensed local environment; record the case and limits of any check rather than claiming unperformed verification.
